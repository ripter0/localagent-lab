# CleanSignal - Citizen Pollution Reporting Platform\n\nA web application that enables citizens to report pollution incidents in their communities.\n\n## Features\n\n- 📝 Submit pollution reports with location, type, severity, and description\n- 🗺️ View recent reports on a map-friendly interface\n- 📊 Track report status (pending, verified, resolved)\n- 🏙️ Multiple predefined locations for easy reporting\n- 🎨 Clean, responsive UI design\n\n## Tech Stack\n\n- **Backend:** FastAPI (Python)\n- **Database:** SQLite (production-ready for PostgreSQL)\n- **Frontend:** HTML/CSS/JavaScript\n- **Templates:** Jinja2\n\n## Quick Start\n\n### Prerequisites\n\n- Python 3.8+\n- pip package manager\n\n### Installation\n\n1. Clone or download this project\n2. Install dependencies:\n   ```bash\n   pip install -r requirements.txt\n   ```\n\n3. Configure environment (edit .env if needed):\n   ```bash\n   cp .env.example .env\n   # Edit .env with your settings\n   ```\n\n4. Initialize database:\n   ```bash\n   python database_init.py\n   ```\n\n5. Run the application:\n   ```bash\n   python app.py\n   ```\n\n6. Open browser: http://localhost:8000\n\n## API Endpoints\n\n- `GET /api/reports` - List recent reports\n- `GET /api/reports/{id}` - Get single report\n- `POST /api/reports` - Create new report\n- `GET /api/locations` - Get available locations\n- `GET /api/stats` - Get pollution statistics\n\n## Project Structure\n\n```\ncleansignal/\n├── app.py              # FastAPI application\n├── config.py           # Configuration settings\n├── model_config.py     # Database models\n├── routing.py          # API routes\n├── database_init.py    # DB initialization\n├── requirements.txt    # Python dependencies\n├── .env                # Environment variables\n├── README.md           # This file\n├── templates/          # HTML templates\n│   ├── index.html\n│   └── about.html\n├── static/             # CSS, JS files\n│   ├── style.css\n│   └── app.js\n└── data/               # Database storage\n```\n\n## Security Notes\n\n- Change SECRET_KEY in production\n- Use HTTPS in production\n- Implement proper authentication for user accounts\n- Validate all user inputs\n\n## License\n\nMIT License - Feel free to use and modify.\n\n## Contributing\n\nContributions welcome!
