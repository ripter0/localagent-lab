# Rules for every task

- Always read a file before editing it. Never claim a file already contains something without reading it first.
- After every edit, read the changed part again and check it is correct.
- After changing code, run the tests or the script if there are any, and report the real result.
- Make the smallest change that does the task. Do not touch unrelated code.
- If you are not sure, say so. Do not guess file contents, versions, or results.
- The user is learning Python: explain changes in a few short lines.
- Commands run on Windows (cmd/PowerShell), not Linux.
